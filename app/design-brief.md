# Nobbie's Gallery: design brief

Design read: a premium dark portfolio for a Nigerian graphic, brand and website designer, built as a faithful recreation of the reference portfolio at abirrk.framer.website with the orange accent replaced by blue.
Concept spine: a gallery with the lights down; the work is the light source.
Delivery tier: editorial.
Animation mode: non-animated, user asked to recreate the reference exactly ("Do not redesign it. Recreate it.").
Palette: bg #010000, text #fff / #c2c2c2, accent blue #1a5cff (text tint #5b94ff), hairlines rgba(255,255,255,.1). Locked to the reference's black and white with the user's brand blue replacing orange.
Type: Inter Tight (stand-in for Creato Display) with DM Serif Display italic for emphasised words, as in the reference.
Sections (reference order): nav, hero, about, services, work, CTA banner, highlights, process, pricing, FAQ, testimonials, marquee, footer. Experience timeline removed by request.
Assets: user's portrait, logo and 44 portfolio images, unaltered apart from resizing. Generated visuals are decorative only (glow backdrops, process objects).
CTAs: every enquiry opens a WhatsApp dialog that builds a prefilled wa.me message for +2348142056679.
