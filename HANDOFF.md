# Nobbie's Gallery source

The project comes in 3 zips. Extract ALL THREE into the SAME folder (merge when asked) so you get one `nobbies-gallery` folder with an `app` folder inside.

Run locally: cd app, bun install, bun run dev.
Vercel: copy app/vite.config.vercel.ts over app/vite.config.ts, then import the repo with Root Directory = app.
